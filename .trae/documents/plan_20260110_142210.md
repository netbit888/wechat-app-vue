# 修复Vuex Mutation错误

## 错误信息
`[vuex] unknown local mutation type: SET_USER, global type: user/SET_USER`

## 问题根源
1. **Actions中调用了不存在的Mutation**：在`src/store/modules/user/actions.js`中，有4处调用了`commit('SET_USER', user)`
2. **实际定义的Mutation名称不同**：在`src/store/modules/user/mutations.js`中，定义的是`SET_USER_INFO`而不是`SET_USER`
3. **功能差异**：
   - `SET_USER_INFO`：合并用户信息 (`{ ...state.currentUser, ...userInfo }`)
   - 但actions中需要的是完全替换用户信息

## 解决方案
在`mutations.js`中添加`SET_USER` mutation，用于完全替换用户信息：

```javascript
// src/store/modules/user/mutations.js
export default {
  // 现有代码...
  
  // 添加SET_USER mutation
  SET_USER(state, user) {
    state.currentUser = user
  },
  
  // 现有代码...
}
```

## 实现步骤
1. 修改`src/store/modules/user/mutations.js`文件
2. 添加`SET_USER` mutation，用于完全替换用户信息
3. 保持现有`SET_USER_INFO` mutation不变，继续用于合并用户信息
4. 不需要修改actions.js，因为它们已经正确调用了`SET_USER`

## 预期效果
- 修复Vuex Mutation错误
- 确保用户信息能正确设置
- 保持代码的可读性和一致性
- 不影响现有功能
