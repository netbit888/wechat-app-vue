## 功能需求
完善"切换账号"按钮功能，实现：
1. 点击按钮后退出当前账号
2. 跳转到登录页面，允许用户登录新账号
3. 提供友好的用户体验

## 实现方案

### 1. 添加切换账号处理函数
在`setup`函数中添加`handleSwitchAccount`函数：

```javascript
const handleSwitchAccount = () => {
  if (confirm('确定要切换账号吗？')) {
    userStore.logout()
    router.push('/auth/login')
  }
}
```

### 2. 绑定点击事件
为切换账号按钮添加点击事件：

```html
<button class="logout-button" @click="handleSwitchAccount">切换账号</button>
```

### 3. 返回函数引用
在`return`对象中添加`handleSwitchAccount`，使其在模板中可用
